# 🎂 우리 가족 기념일 (Anniversary Memo)

가족들의 기념일을 함께 기록하고, 매년 그날이 오면 알림을 받는 앱입니다.
구글 계정으로 로그인하고, 초대코드만 알면 다른 가족 구성원도 들어와서 같이 기록하고 볼 수 있어요.

## 주요 기능

- **가족 그룹 공유**: 가족 그룹을 만들면 6자리 초대코드가 생깁니다. 가족은 구글 로그인 후 초대코드만 입력하면 참여할 수 있고, 모두가 같은 기념일 목록을 실시간으로 함께 보고 기록합니다.
- **여러 가족 그룹(탭)**: 홈 화면 위쪽 `＋ 가족 그룹` 으로 다른 가족 그룹(예: 처가, 시댁)을 추가로 만들거나 그 그룹의 초대코드로 참여할 수 있고, 탭으로 오갈 수 있습니다.
- **중복 알림 합치기**: 여러 가족 그룹에 같은 기념일(같은 기념일명·날짜·반복 방식)이 있으면 알림은 한 번만 울리고, `김씨네 · 이씨네 공통 기념일` 처럼 해당 그룹들을 함께 표시합니다.
- **내 프로필**: 이름, 아이콘(이모지), 색상을 정하고, 기념일마다 해당 인물을 체크할 수 있습니다.
- **홈 화면**
  1. 오늘 날짜와, 가장 가까운 기념일부터 날짜순으로 **D-day와 남은 일수** 표시 (매년 반복 기념일은 몇 주년인지도 표시)
  2. **가족 목록**: 가족을 누르면 그 가족의 기념일만 볼 수 있음
- **기념일 입력**: `＋ 기념일 입력` 버튼으로 가족 선택(새 가족 바로 추가 가능) → 기념일명 → 날짜 → 내용 작성
- **알림 방식 선택**: `매년 반복` 또는 `1회성`. 기념일 당일 오전 9시에 알림이 옵니다.
- 기념일 수정/삭제, 가족 이름 변경/삭제, 초대코드 복사·공유, 기록한 사람 표시

## 기술 스택

- [Expo](https://expo.dev) (React Native, TypeScript) + Expo Router
- Firebase Firestore (그룹 데이터 공유, 실시간 동기화) + Firebase 구글 로그인 (@react-native-google-signin)
- expo-notifications (기기 로컬 알림 예약)

## 실행 방법

### 1. Firebase 프로젝트 준비 (최초 1회)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만듭니다.
2. **Authentication → 로그인 방법**에서 **Google** 을 사용 설정하고, 표시되는 **웹 클라이언트 ID**를 복사해 둡니다.
   - **프로젝트 설정 → 내 앱 → Android 앱 추가**: 패키지 이름 `com.happyfamily.anniversarymemo`, SHA-1 `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25` (GitHub Actions 빌드의 서명 키)
3. **Firestore Database**를 만듭니다 (프로덕션 모드).
4. **Firestore → 규칙** 탭에 이 저장소의 [`firestore.rules`](./firestore.rules) 내용을 붙여넣고 게시합니다.
   (또는 Firebase CLI로 `firebase deploy --only firestore:rules`)
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가**를 해서 SDK 설정 값을 확인합니다.

### 2. 환경 변수 설정

```bash
cp .env.example .env
# .env 파일에 Firebase 웹 앱 설정 값을 채워 넣기
```

### 3. 앱 실행

```bash
npm install
npx expo start
```

휴대폰에 **Expo Go** 앱을 설치하고 터미널의 QR 코드를 찍으면 바로 실행됩니다.
스토어 배포용 앱은 `npx eas-cli@latest build` 로 빌드할 수 있습니다.

## 사용 방법

1. 첫 사용자: **구글 계정으로 시작하기** → **새 가족 그룹 만들기** → 그룹 이름, 내 이름/아이콘 입력 → 초대코드 발급
2. 설정 화면에서 초대코드를 가족에게 **공유**합니다.
3. 다른 가족: **구글 계정으로 시작하기** → **초대코드로 참여** → 초대코드, 내 이름/아이콘 입력
4. 홈에서 `＋ 가족 추가` 로 가족(예: 우리집, 큰집, 외가)을 만들고 `＋ 기념일 입력` 으로 기념일을 기록합니다.

## 알림 동작 방식

- 알림은 각자의 휴대폰에 **로컬 알림**으로 예약됩니다. 가입한 모든 가족 그룹의 기념일이 대상입니다. 다른 가족이 기념일을 추가해도 내 앱이 동기화될 때 자동으로 내 휴대폰 알림에 반영됩니다.
- `매년 반복`: 매년 같은 날 오전 9시. 2월 29일 기념일은 평년에는 2월 28일에 알려드립니다.
- `1회성`: 지정한 날짜 오전 9시 한 번만. 지난 1회성 기념일은 홈 화면에서는 숨겨지고, 가족 화면에서 '지남'으로 표시됩니다.
- 알림이 오지 않으면 휴대폰의 알림 권한을 확인하고, 설정 화면의 **알림 다시 설정**을 눌러 주세요.

## 보안

- 구글 계정으로 로그인한 사람만 사용할 수 있고, 내 프로필과 가입한 그룹 목록(`users/{uid}`)은 본인만 읽고 쓸 수 있습니다.
- 초대코드(6자리, 약 8억 가지 조합)를 아는 사람만 그룹 구성원이 될 수 있고, 구성원만 그룹의 데이터를 읽고 쓸 수 있습니다.
- 예전 버전(익명 로그인)을 쓰던 기기는 구글 로그인 시 기존 그룹에 자동으로 다시 연결됩니다.
